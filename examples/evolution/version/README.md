# Version

`alienctl --version` prints the version declared by the application.

Build the CLI from this directory:

```sh
go build -o alienctl .
```

Print the version:

```sh
./alienctl --version
```

```text
2.0.0
```

See [Evolving a CLI](../../../docs/08-evolving-a-cli.md) for release authority, lifecycle, replacement, and version presentation.
